my_dict = {"name": "Alice", "age": 25}

# **7교시: 실행 버튼을 없앤다 (자동화)**

## **1. 스케줄러(Scheduler)가 왜 필요할까요?**

- **문제 상황:** 지금까지 우리가 만든 훌륭한 해킹 탐지 프로그램들은 전부 **사람이 마우스로 실행 버튼을 누르거나 터미널에 명령어를 입력해야만** 작동했습니다.
- 하지만 해커들은 우리가 퇴근한 새벽 3시에도 공격을 시도하죠. 그때 침대에 누워있는 우리 대신 프로그램을 실행해 줄 존재가 바로 **스케줄러**입니다.
- 방법은 크게 두 가지가 있습니다.
    1. **파이썬 안에서 실행하는 것:** `schedule` 패키지 사용.
    2. **운영체제(OS)가 실행하는 것:** `cron` 도구 사용.

---

## **2. 파이썬 안에서 도는 스케줄러: `schedule` 패키지 (7.1)**

파이썬의 `schedule` 라이브러리는 사람이 읽기 아주 쉬운 문장 형태로 코드를 짤 수 있는 게 장점입니다.

```python
import schedule
import time

def job():
    print("점검합니다")

# 1. 2초마다 job 이라는 함수를 실행하도록 스케줄러 목록에 등록합니다.
schedule.every(2).seconds.do(job)

# 2. 실습을 위해 딱 6번(6초 동안)만 반복하면서 스케줄러를 확인합니다.
for i in range(6):
    
    # 3. 현재 시각을 확인하여, 등록된 작업(2초 주기) 중 실행할 시간이 된 작업이 있다면 지금 실행합니다.
    schedule.run_pending()
    
    # 4. CPU 과부하를 막고 실제로 시간이 흘러가도록 프로그램을 1초 동안 멈추고 대기합니다.
    time.sleep(1)
```

반드시 아래에서 **`schedule.run_pending()`을 주기적으로 계속 호출해 줘야함.**

## 3. 컴퓨터가 꺼져도 OS가 실행해준다: **`cron`** 다섯 칸

`schedule` 패키지는 치명적인 약점이 있습니다. **그 파이썬 프로그램이 켜져 있는 동안만** 작동한다는 점이죠. 창을 닫거나 컴퓨터를 끄면 멈춥니다 [schedule, 창을].반면, 리눅스/맥 운영체제 자체에 내장된 `cron`은 프로그램이 종료되어 있어도 정해진 시각에 운영체제가 깨워서 실행해 줍니다.

`cron`은 빈칸으로 나뉜 **다섯 칸(분 시 일 월 요일)**으로 시간을 표현합니다.

- `0 6 * * *` → 분이 0, 시가 6이고 나머지는 별표(매번)이므로 **매일 오전 6시 정각**
- `/5 * * * *` → 분 자리에 `/5`가 있으므로 **5분마다** 실행
- 요일은 `0`이 일요일이며, 금요일은 `5`가 됩니다.
- *(주의: `cron`은 리눅스/맥용이라 윈도우에는 없습니다. 윈도우는 '작업 스케줄러'를 씁니다.*
