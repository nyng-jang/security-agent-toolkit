## **`json`** 라이브러리의 4대 함수 구별

LLM은 list, dict 개념 모름. 오직 **텍스트(문자열)**만 읽고 쓰기 가능! → Python data를 문자열로 바꿔 전송해야함

- 함수 이름 뒤 + `s`  ⇒ String
- 함수 이름 뒤 + `s` X ⇒ File
    
    
    | **함수 이름** | **하는 역할** | **이번 교시에서의 용도** |
    | --- | --- | --- |
    | **`json.load(f)`** | **파일**을 읽어서 파이썬 데이터로 변경 | 저장된 경보 파일(`events_1007.json`) 읽기 |
    | **`json.dumps(data)`** | 파이썬 데이터를 **문자열**로 변경 | 쪼갠 묶음(리스트)을 LLM에 보낼 글자로 바꿀 때 |
    | **`json.loads(string)`** | **문자열**을 파이썬 데이터로 변경 | LLM이 보낸 답변 글(JSON 배열)을 파이썬 리스트로 바꿀 때 |
    | **`json.dump(data, f)`** | 파이썬 데이터를 **파일**로 저장 | 최종 모은 요약본을 JSON 파일로 저장할 때 |

💡 **꿀팁:** 한글이 깨지지 않고 올바르게 문자로 보이게 하려면 `ensure_ascii=False` 옵션을 꼭 넣어줘야함!!

# 4교시: 위험도 순 정렬 및 모듈화

<aside>
🔠

- 트리아지(Triage): 수많은 경보 중 어떤 위험을 먼저 처리할지 순서를 정하는 것
    - 수백 건의 경보가 발생했ㅇ르 때 발생 시간순으로 나열해두면 즉시 대응해야하는 치명적 공격을 놓칠 수 있음. 가장 위험한 것부터 정렬해서 보고서 상단에 올려야 함.
- 문자열 메서드 **`.lower()`**와 대소문자 구분
    - 컴퓨터는 `"High"`, `"high"`, `"HIGH"`를 완전히 다른 글자로 인식합니다 (`"High" == "high"` 결과는 `False`).
    - LLM은 답변을 생성할 때 대소문자를 무작위로 섞어 쓸 수 있습니다. 이를 정확히 비교하기 위해 **`.lower()` 메서드로 영문자를 모두 소문자로 변환한 뒤 비교**해야 누락 없이 안전하게 분류 가능
    - **주의점:** `.lower()`나 `.upper()` 같은 문자열 메서드는 **원본 데이터를 직접 변경하지 않고, 바꾼 새로운 문자열을 반환**할 뿐입니다. 원본을 바꾸려면 `s["risk_level"] = s["risk_level"].lower()`처럼 다시 대입해야함
</aside>

## **파일 모듈화와 `importlib.reload()`**

- **`import`의 특징:** 주피터 노트북(Colab) 환경은 한 번 `import`한 파이썬 파일(`.py`)의 내용을 메모리에 기억(캐싱)해둠
- **문제점:** 만약 여러분이 `event_summarizer.py` 파일의 코드를 수정하고 노트북에서 다시 `import event_summarizer`를 실행하더라도, 컴퓨터는 수정된 내용이 아닌 **맨 처음 읽었던 과거의 코드**를 계속 실행함
- **해결책 (`importlib.reload`):** 수정한 파이썬 코드를 즉시 새로고침하여 적용하고 싶을 때는 반드시 `importlib` 모듈을 불러와 `importlib.reload(모듈이름)`을 실행해줘야 함

# 5교시: 요약을 요약

<aside>
🔠

- 프롬프트 체이닝 (Prompt Chainig): LLM에게 한 번에 복잡한 작업을 다 시키지 않고, 단계를 나눠 이전 단계의 결과물을 다음 단계의 입력값으로 사용하는 방식
    - LLM은 처리할 정보가 한 번에 넘 많으면 중요한 내용 놓치거나 엉뚱한 답 낼 확률 높음. 단계를 쪼개면 정확도 up
- 경영진 요약 (Executive Summary): 바쁜 결정권자가 보고서 맨 앞 부분만 보고도 전체 상황을 한눈에 파악할 수 있도록 작성하는 2~3문장짜리 핵심 요약
    - 상세한 수치나 세부 내역보다는 전체적인 위험 흐름과 시급하게 확인해야 할 거시적 맥락을 담음
</aside>

## **빈 문자열은 「답이 없다」는 뜻**

```python
overview = ""
print(overview == "") # True
```

| **값** | **`== ""`** | **뜻** |
| --- | --- | --- |
| `""` | `True` | 아무 글자도 없다 — `call_llm` 이 실패하면 이 값을 돌려준다 |
| `" "` | `False` | 빈칸 한 글자가 있다 |

### 문법 상자 · 함수를 이어 붙이면 파이프라인이 됩니다

```
def step1(x):return x +1
def step2(x):return x *10
print(step2(step1(2)))
# 30
```
