# 2026-10-14 (수)

## 찾아본 것

- 서버에 마우스가 없는 이유: 일반 PC와 달리 기업이나 서비스에서 사용하는 리눅스 서버는 CLI(Command Line INterface) 기반 환경. 마우스나 화면을 띄우는 메모리와 CPU 자원을 절약하고, 보안성과 안정성을 극대화하기 위해서.
- 서버에서 로그를 옮기고 백업하는 방법:
    - `cp` (Copy) : 원본 파일은 그대로 두고, 동일한 내용을 지정한 경로에 하나 더 생성함.
    - `mv` (Move) : 원본 파일의 위치를 다른 디렉터리로 옮기거나, 파일의 이름을 변경함.

## 오늘 새로 쓴 명령

touch, cp, mv, rm, Tab 자동 완성

## 찾은 옵션

폴더째 복사 - `cp -r backup backup2`

덮어쓰기 전에 묻기 -  `cp -i a.log backup/`

폴더째 지우기 - `rm -r backup2`

### `r` (recursive, 재귀적)

- 폴더(디렉터리) 안의 내용물까지 **하위 폴더와 파일 전체를 통째로** 대상으로 지정할 때 사용

### `i` (interactive, 대화형 / 확인)

- 파일을 덮어쓰거나 중요한 작업을 할 때, "정말 덮어쓸까요?" 하고 사용자에게 한 번 더 확인(질문)하는 옵션

## mv 의 두 가지 쓰임

이름 바꾸기: 파일의 이름을 변경할 때 사용합니다 (예: `b.log`의 이름을 `c.log`로 바꿈)

옮기기: 파일의 위치를 다른 폴더 안으로 이동할 때 사용합니다 (예: `c.log`를 `backup` 폴더 안으로 옮김)
