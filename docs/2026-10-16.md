## 찾아본 것

서버에서 설정 파일을 고치는 방법: 보안 담당자나 시스템 관리자는 GUI나 무거운 편집기를 사용할 수 없는 원격 서버 환경에서 설정 파일을 수정할 때 주로 터미널 기반의 텍스트 에디터를 사용한다. 대부분의 리눅스 서버에 기본적으로 설치되어 있는 `vim` 이나 `nano` 같은 편집기를 열어 설정 파일을 직접 수정한다. 

## 오늘 새로 쓴 명령

vim

## vim 으로 한 것

입력 모드로 들어가는 키: `i`
일반 모드로 돌아오는 키: `Esc`
저장하고 나가는 명령: `:wq`
저장 없이 나가는 명령: `:q` 
지운 것을 되돌리는 키: `u`
