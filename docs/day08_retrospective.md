# 1과목 회고 (장나영)

## 내가 만든 것
- 보안 경보를 묶음으로 요약하고, 위험도순 보고서를 만들어 파일로 저장한 뒤 알림까지 보내는 자동화 파이프라인을 만듦.
- `pipeline.run_pipeline("config.json", "2026-10-08")` 명령 한 번으로 전체 프로세스가 동작함.

## 가장 어려웠던 것
- 특정 파일이 실제로 생성되었는지 판별하는 `os.path.exists()` 문법의 사용법과 경로 지정이 헷갈림.
- 생성된 마크다운 보고서 파일을 가져와서 `splitlines()`로 줄 단위로 쪼갠 뒤, 소제목\(`## `)으로 시작하는 특정 라인만 필터링하여 출력하는 조건문 로직 구현

## 리뷰에서 찾은 것과 고친 것
- 모델 이름이 코드 내에 하드코딩되어 있던 문제를 발견하여 `config.json` 설정 파일에서 동적으로 불러오도록 수정
- 외부 알림 서버로 요청을 보낼 때 `timeout=5` 제한과 `try/except` 예외 처리가 누락되어 서버가 꺼지면 파이프라인 전체가 멈추는 에러를 수정하여 장애 허용(Fault Tolerance) 확보
- 딕셔너리 참조 시 철자 오류(`sevrity` -> `severity`)로 인한 실행 에러를 트레이스백을 통해 해결
- 데이터 앞뒤에 공백이 붙거나(`" high"`) 대소문자가 섞여 통계가 누락되던 논리 에러를 `.strip().lower()` 문법을 적용해 교정

## 캡스톤에서 더 해 보고 싶은 것
- 알림을 가상 서버가 아닌 슬랙(Slack)이나 디스코드 같은 실제 메신저 웹훅과 연동하여 실시간 경보 시스템을 구축해보고 싶다.
